# 时间轴拖动与空白新建

日期：2026-10-14。状态：功能实现与本地验证完成。

## 使用方式

在进度看板和人员看板中，单击项目块或外置名称打开编辑弹窗。按住移动超过 6px 后进入拖动。

- 横向按天吸附，同时移动开始、结束日期，保持包含结束日在内的工期。
- 纵向调整显示行；拖入另一条产品线时，同时变更产品线。
- 目标行发生工期重叠时，保留目标日期，在目标产品线内寻找最近的可用行；同距离优先向下，必要时增加一行。
- 拖动中显示半透明落点、目标产品线、起止日期及最终行号。自动换行也会在松手前预览。
- 靠近时间轴左右边缘时自动横向滚动。按 Esc、指针取消或松手落在时间轴外时恢复原位。
- 松手后一次保存日期、产品线和布局。保存期间显示等待状态；失败保持原数据并提示。未超过拖动距离、未改变位置时不发移动请求。
- 拖动后的松手不会再次打开编辑或新建弹窗。

例如，10/14–10/21 的项目向右移两天并拖入另一产品线后，保存为目标产品线的 10/16–10/23；目标行冲突时自动选择最近可用行。

## 布局与数据

项目增加可空的 `layoutRow` 字段。旧项目缺失字段时继续自动分配；手动行号优先。手动行号不随缩放改变，名称沿用行内或上方避让；固定行内名称过密时截断显示，悬停查看完整名称。

首次移动时，固定源产品线和目标产品线现有项目的实际行号，再为拖动项目选择可用行，以保持周边块位置稳定。隐藏负责人和当前时间范围外的项目同样参与日期冲突判断。日期有共同一天即视为工期重叠。

采用 `PUT /api/projects/:id/move`，同时提交开始日期、结束日期、目标产品线、期望行号、项目原更新时间，以及源/目标产品线全量项目的行号与更新时间快照。后端校验产品线存在、工期未改变、快照完整且版本未过期，重新计算可用行，并在一次受锁保护的文件原子替换中保存。返回完整项目列表，使前端使用服务器最终布局。相关项目已被他人修改、增加或删除时提示刷新后重试。文件事务锁适用于现有单进程服务；扩展到多进程前需更换锁机制或数据存储。

编辑弹窗更改其他字段时保留行位置；调整日期或产品线后按相同规则消解布局冲突。默认负责人和状态不会因拖动而改变。

## 点击空白新建

- 点击产品线内空白：打开现有新建弹窗，预填该产品线、点击位置对应日期和期望行。开始、结束日期先设为同一天，允许修改。
- 点击右侧看板底部空白：打开新建弹窗；能够映射日期时预填日期，产品线由用户选择。
- 无项目、无产品线时仍可点击看板空白打开新建弹窗，并使用现有新建产品线流程。
- 点击项目、产品线标题、刻度表头、工具栏、侧栏、滚动条等控件时，执行其原有操作。
- 点击仅打开草稿弹窗；保存成功才创建项目，取消不写数据。日期换算包含横向滚动偏移。

## 实现范围

前端：统一逻辑行分配工具、指针拖动控制、落点预览、空白点击定位，以及新建表单预填。

后端：兼容 `layoutRow`，移动接口及文件事务，旧数据无需批量迁移。预览使用隔离的数据副本和真实本地 API。

## 验收

1. 普通单击编辑；6px 以下移动仍为点击，拖动结束不误弹窗。
2. 左右拖动、跨月跨年移动保持工期；100/240/500px 缩放下按天吸附。
3. 上下和跨产品线移动可保存，刷新后行号、日期和产品线一致。
4. 冲突自动寻找最近可用行，不移动目标日期；隐藏项目也参与冲突。
5. 空产品线可接收项目，重复移动同一块不会残留占位。
6. Esc、越界松手、请求失败和过期数据均有正确恢复行为。
7. 空白新建的日期、产品线预填正确；底部空白与空状态可用；取消无写入。
8. 原有短条名称、连接线、周一刻度与本周底色无回归。
